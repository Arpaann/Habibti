# HABIBTI — The Album Cover Transformation Studio

A high-performance, client-side web application inspired by the mysterious, monochrome, veiled masking-tape aesthetic of Drake's *Habibti* artwork.

Developed by **ARPN$** ([linktr.ee/NapraB](https://linktr.ee/NapraB)).

Repository: [https://github.com/Arpaann/Habibti](https://github.com/Arpaann/Habibti)

---

## ✨ Features

- **2000×2000 Ultra-HD Master Tape Artwork:** Authentic crepe paper fibers, masking tape seams, crinkles, and torn corner details.
- **Precision Eye Fitting & Alignment:**
  - Photo zoom and omnidirectional drag-to-position.
  - Head tilt / rotation straightening (-15° to +15°).
  - Customizable tape slit dimensions (width, height, vertical position).
  - Toggleable pupil alignment guide crosshair overlay.
- **Classic High-Contrast B&W Photographic Treatment:** Deep blacks and smoky eye pop with translucent tape body silhouette.
- **Aesthetic Modes:**
  - *Original Tape* (Drake's official cover tape texture)
  - *Masking Tape* (Procedural clean beige crepe tape)
  - *Dark Noir* (Obsidian black gaffer tape)
- **High-Resolution Export:** Instant 2000×2000 master JPEG download with zero watermarks.
- **100% In-Browser Privacy:** Processed entirely in client-side HTML5 Canvas. Zero images or data are sent to any server.

## 🚀 Quick Start

### Installation
```bash
git clone https://github.com/Arpaann/Habibti.git
cd Habibti
npm install
```

### Running Locally
```bash
npm run dev
```
Open **[http://localhost:8888](http://localhost:8888)** in your browser.

*(On Windows, you can simply double-click `start.bat`)*

### Production Build
```bash
npm run build
npm run preview
```
